# Converter_Pdf-_Docs

**Converter_Pdf-_Docs** is a user-friendly tool designed to help you easily convert files between PDF and popular document formats like DOCX and TXT. Whether you’re a student, professional, or anyone needing quick file conversions, this project aims to make the process simple, clear, and efficient.

---

## 🚀 Features

- **PDF to Word/Doc**: Convert PDF files into editable DOCX or TXT documents so you can make changes or extract data.
- **Word/Doc to PDF**: Change your DOCX or TXT files into PDF format for easy sharing and printing.
- **Batch Conversion**: Convert multiple files at once to save time and effort.
- **Simple Interface**: Designed to be straightforward so anyone can use it, even without technical knowledge.
- **Drag and Drop Support**: Easily add files for conversion by dragging them into the application window.
- **Fast & Reliable**: Uses well-known libraries for accurate and quick conversions.
- **Preserves Formatting**: Maintains as much of the original document formatting as possible during conversion.
- **Cross Platform**: Works on Windows, macOS, and Linux as long as Python and dependencies are installed.
- **Open Source**: Free to use and modify according to your needs.

---

## 🛠️ Tech Stack

- **Programming Language**: Python 3.7+
- **PDF Handling**: [PyPDF2](https://pypi.org/project/PyPDF2/) – Extracts text and information from PDF files.
- **Word Document Handling**: [python-docx](https://pypi.org/project/python-docx/) – Reads, creates, and modifies DOCX files.
- **PDF Generation**: [fpdf](https://pypi.org/project/fpdf/) – Creates PDF files from scratch.
- **User Interface**: [tkinter](https://docs.python.org/3/library/tkinter.html) – For building graphical user interfaces (or another GUI library if specified).
- **Other Libraries**: See `requirements.txt` for the complete list of dependencies.

## 📦 Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Suman9038/Converter_Pdf-_Docs.git
   cd Converter_Pdf-_Docs
   ```

2. **(Optional) Create a Virtual Environment**
   ```bash
   python -m venv venv
   # Activate on Windows
   venv\Scripts\activate
   # Or activate on Mac/Linux
   source venv/bin/activate
   ```

3. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

---

## 🖥️ How to Use

1. **Start the Application**
   ```bash
   python main.py
   ```
2. **Follow On-Screen Instructions**
   - Choose whether you want to convert from PDF to DOCX/TXT, or from DOCX/TXT to PDF.
   - Select your files (drag-and-drop or use the file selector).
   - Pick your output folder and format.
   - Start the conversion and your files will be ready in seconds!
